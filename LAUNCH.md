# Startup Toolkit - Product Launch & Build Journey

> Built with passion by **Mariyam Ali K.** ([@Mariyamalikho](https://github.com/Mariyamalikho))

Welcome to the official launch of **Startup Toolkit**, an all-in-one web application designed for early-stage founders, startup teams, and students to brainstorm, map, validate, and present startup ideas.

---

## 🚀 Key Feature Walkthrough

### 1. Landing Page & Supabase Authentication

- **Public Hero & Feature Showcase**: Clean, modern dark/light mode landing page introducing the toolkit.
- **Secure Authentication**: Built with Supabase Auth supporting Email/Password signup & login with persistent sessions.

### 2. Venture Dashboard & Management

- **Project Grid & Search**: Manage multiple startup ventures with live text search, category filters, creation modals, and delete confirmations.
- **Autosave Engine**: Custom debounced autosave synchronizes project metadata and tool state across devices seamlessly.

### 3. Interactive Ideation & Strategy Canvases

- **Empathy Map Canvas**: 4-quadrant customer empathy map (Says, Thinks, Does, Feels) with customizable, drag-and-drop sticky notes.
- **9-Box Business Model Canvas**: Interactive Business Model Canvas grid covering Value Propositions, Customer Segments, Revenue Streams, Key Activities, and more.
- **Brainstorming Board & Validation Tracker**: Freeform brainstorming board and Lean Startup validation experiment tracker with milestone timelines.

### 4. AI-Powered Assistant & Pitch Deck Presenter

- **AI Generator**: Instant startup problem & value proposition generator modal to jumpstart canvas brainstorming.
- **Pitch Deck Slide Generator**: Transforms canvas insights into slide presentations complete with theme customizers and fullscreen presenter mode.

### 5. Export Engine & Production Deployment

- **Client-Side PDF Exporter**: Export canvas reports and pitch decks directly to PDF.
- **Vercel Production Deployment**: Fully configured single-page application (`vercel.json`) with optimized Rollup code-splitting chunks (<200KB entry size).
